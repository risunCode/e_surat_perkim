# Thinking Style

Untuk setiap task yang kompleks:
1. Analisis dulu sebelum langsung execute
2. Kalau ada yang gak yakin, bilang "wait" dan reconsider
3. Validasi approach sebelum implement
4. Kalau sadar ada kesalahan, langsung koreksi tanpa diminta

Untuk task simple, langsung execute tanpa overthinking.
